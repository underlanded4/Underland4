# UNDERLAND V4 — Web + Pack

Web oficial del servidor (GitHub Pages) y descarga del pack de recursos.

- `index.html` → página publicada con la IP, cómo entrar y botón de descarga.
- El pack se publica como **Release** (`resource_pack.zip`) para descarga directa:
  https://github.com/underlanded4/Underland4/releases/latest/download/resource_pack.zip

Para actualizar el pack tras cambios: regenerar en el servidor
(`/ce workflow default`), copiar el zip y subirlo a un nuevo Release.
